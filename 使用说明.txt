============================================
    微信群聊 AI 总结 - 使用说明
============================================

这是最小入门说明。完整功能、隐私边界、关注推送、实际 Obsidian 输出截图和公开
fork 说明，请优先阅读 README.zh-CN.md。


【安装（只需一次）】

第一步：从公开 repo 获取源码

  打开 Terminal，运行：

    git clone https://github.com/IndelibleVivi/we-groupchat-obsidian.git
    cd we-groupchat-obsidian
    ./启动.command

  项目是 source-only CLI 分发，不提供 .dmg 或 bundled Python runtime。


---------------------------------------------
⚠ 遇到安全提示怎么办？
---------------------------------------------

如果 macOS 拦截 .command 文件，可以按下面的方法解除：

  方法一（推荐）：右键打开

    1. 在「启动.command」文件上 右键（或两根手指点触控板）
    2. 选择「打开」
    3. 弹窗里再点「打开」

    * 只有第一次需要这样做，以后双击就能直接打开。

  方法二：从系统设置解除

    如果方法一没用：

    1. 打开 系统设置 → 隐私与安全性
    2. 往下滚，找到「启动.command 已被阻止」的提示
    3. 点右边的「仍要打开」
    4. 输入电脑密码确认


---------------------------------------------
第二步：确认 dependencies 安装
---------------------------------------------

首次运行或 requirements.txt 更新时，脚本会询问是否：

  1. 在当前文件夹创建或更新独立的 Python 环境（.venv）
  2. 安装 Python dependencies
  3. 检查微信数据目录和授权状态

  输入 y 才会继续安装；不同意就退出，不会偷偷改环境。
  * .venv 是项目自己的运行环境，不会污染你电脑里别的 Python。
  * 如果需要重新提取数据库 key 或重新授权，脚本会明确提示你使用
    「刷新数据源.command」或带 --allow-wechat-resign 的命令，不会在普通启动时偷偷重签名。


---------------------------------------------
第三步：设置 API Key
---------------------------------------------

  1. 菜单栏出现 💬 图标后（在屏幕上方），点击它
  2. 选择「设置」
  3. 填入你的 AI 服务 API Key

支持的 AI 服务：

  通义千问（默认）  → dashscope.console.aliyun.com
  DeepSeek          → platform.deepseek.com
  Claude            → console.anthropic.com
  OpenAI            → platform.openai.com
  Ollama 本地       → 无需 Key，需先安装 Ollama

  * 云端 provider 会收到你要求总结的聊天文本；如果需要内容完全留在本机，请使用 Ollama。



============================================
    日常使用
============================================

  1. 确保微信已启动并登录
  2. 双击「启动.command」
  3. 菜单栏出现 💬 图标
  4. 点击图标 → 选择群聊 → 查看/生成总结

配置文件位置：
  ~/.we-groupchat-obsidian/config.json

总结和缓存位置：
  ~/.we-groupchat-obsidian/



============================================
    常见问题
============================================

Q：提示「未找到 Python3」或「Python 版本太低」？
A：本工具需要 Python 3.10 以上版本。
   启动脚本会自动检测版本，如果版本太低且已安装 Homebrew，
   会先征求同意，再尝试安装 Python 3.12。
   如果不想让脚本安装或安装不成功，请手动安装：
   · 方法一（推荐）：去 python.org/downloads 下载最新版本
   · 方法二：运行 brew install python@3.12

Q：提示「重签名失败」/ Operation not permitted？
A：这是因为 macOS 没有授权终端修改应用。
   1. 先完全退出微信
   2. 打开「系统设置」→「隐私与安全性」
   3. 往下滚，找到「App 管理」
   4. 打开「终端」的开关（需要输入密码）
   5. 重新运行「刷新数据源.command」或刚才带 --allow-wechat-resign 的命令
   如果找不到「App 管理」，就找「完全磁盘访问权限」，打开「终端」的开关。

Q：终端提示输入密码，但打字看不见，是不是卡住了？
A：不是。macOS 的 sudo 输入密码时本来就不会显示字符，也不会显示星号。
   直接输入电脑登录密码，然后按回车即可。

Q：微信更新后读不到记录了？
A：先双击「健康检查.command」查看 DB/key、re-sign、missing keys 和 LaunchAgent 状态。
   如果提示需要刷新，运行「刷新数据源.command」。
   这一步可能会要求输入 Mac 登录密码，也可能会退出微信，请先读终端提示。

Q：关闭终端窗口会怎样？
A：关闭终端窗口会退出程序。想退出时直接关窗口或按 Ctrl+C。

Q：公开 repo 更新后怎么升级？
A：先确认当前 checkout 没有需要保留的未提交修改，然后在项目目录运行：

     git pull --ff-only
     ./启动.command

   如果 requirements.txt 有变化，启动脚本会再次询问是否更新 .venv 和 dependencies。

Q：可以保留后台监控，但关掉系统通知吗？
A：可以。在菜单栏打开「关注推送」，点击「后台通知：开/关」。关闭后监控、
   Obsidian 写入和 Daily Digest 仍会继续，只静音自动 banner；手动操作反馈和
   「测试系统通知」仍然可用。

Q：数据存在哪里？
A：配置、密钥缓存、总结记录都在 ~/.we-groupchat-obsidian/ 目录。
   旧 ~/.wechat-summary/ 只作为本机迁移/兼容路径保留。
   Python 依赖环境在当前项目文件夹的 .venv/ 目录。

Q：通过 MCP 发送微信消息失败？
A：MCP 默认只读。发送消息需要先在 ~/.we-groupchat-obsidian/config.json 里显式选择：
   "mcp_send_mode": "dry_run" / "allowlist" / "enabled"
   然后再授予辅助功能权限。
   1. 打开「系统设置」→「隐私与安全性」→「辅助功能」
   2. 找到你运行 MCP Server 的应用（终端、Claude.app 等）
   3. 打开它的开关（需要输入密码）
   4. 重新启动该应用
   发送时微信必须已登录且在运行中，AI 会自动操作微信界面完成发送，
   发送后会自动验证消息是否成功写入数据库。

Q：我要把这个工具分享给别人，发什么？
A：直接发送公开 repo 或中文版 README 链接：

     https://github.com/IndelibleVivi/we-groupchat-obsidian
     https://github.com/IndelibleVivi/we-groupchat-obsidian/blob/main/README.zh-CN.md

   不要重新压缩自己正在运行的 checkout；其中可能已经出现 .venv、本机 runtime、
   cache、日志或私有调试材料。
