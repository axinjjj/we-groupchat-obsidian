# Project Lineage

`we-groupchat-obsidian` is a standalone derivative of
[Qizhan7/mac-wechat-summary](https://github.com/Qizhan7/mac-wechat-summary).
The exact imported upstream baseline commit/date is pending source audit; this
repository does not currently claim a verified upstream SHA.

The original project established the local macOS WeChat database reading,
menu-bar summary, and MCP foundation. This repository keeps that foundation and
continues in a separate direction: local-first group-chat monitoring, Obsidian
knowledge output, daily digest/review workflows, and operational reliability for
long-running personal use.

This repository is not connected to the original project through GitHub's fork
network, and it is not maintained as an upstream pull-request branch. Upstream
attribution and the AGPL-3.0 license are preserved.

This project is not affiliated with, endorsed by, or sponsored by Tencent,
WeChat, or the upstream project maintainers. WeChat is a trademark of its
respective owner. This software reads local user-controlled data on macOS and is
not official WeChat/Tencent software.
